# 🇮🇳 Independence Day 2027

A premium, interactive web experience celebrating **India's 80th Independence Day** on **15 August 2027**.

This project combines a cinematic dark UI, Indian tricolor aesthetics, historical milestones, interactive animations, and responsive design to create a modern Independence Day experience.

---

## ✨ Features

- 🇮🇳 Premium Independence Day themed UI
- ⏳ Live countdown to 15 August 2027
- 📜 Historical timeline of India's freedom struggle
- 🧑‍🦱 Freedom fighters section
- 🎆 Interactive celebration popup with fireworks
- 🎵 Background patriotic music
- ✍️ Patriotic message submission form
- 🔢 300-character message counter
- 💾 Local message storage using browser LocalStorage
- 🧭 Responsive navigation menu
- ✨ Scroll reveal animations
- 🌌 Hero mouse-parallax effects
- 🔝 Back-to-top button
- 📱 Responsive design for desktop, tablet and mobile
- ♿ Accessibility-focused interactions

---

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- CSS Animations
- Intersection Observer API
- LocalStorage API
- Responsive Web Design

## 🎨 Design

The website uses a cinematic dark interface inspired by the Indian tricolor.

🟠 Saffron — Courage & sacrifice
⚪ White — Peace & truth
🟢 Green — Growth & prosperity
🔵 Ashoka Chakra — India's national identity

The interface combines gradients, glassmorphism, glow effects, animations and responsive layouts.

## 📜 Historical Journey

The timeline highlights important milestones from India's freedom struggle:

- Year	Event
- 1857	First War of Independence
- 1919	Jallianwala Bagh
- 1930	Dandi March
- 1942	Quit India Movement
- 1947	India's Independence
- 2027	80 Years of Independence
